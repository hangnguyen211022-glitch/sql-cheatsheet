All examples are written in standard SQL, which is what most SQL tests expect. Databases differ in a few places: MySQL, PostgreSQL and SQLite also accept LIMIT n, SQL Server also uses TOP n, and SQL Server and SQLite use their own date functions (DATEPART and strftime) instead of EXTRACT.
